# Sua estante — web

Versão web do app **Sua estante**, para iPhone (e qualquer navegador). Usa o mesmo servidor do app Android.

## Como instalar no iPhone

1. Abra o endereço do site no **Safari**.
2. Toque em **Compartilhar** → **Adicionar à Tela de Início**.
3. Abra pelo ícone. Entre com seu nome, sua senha e a senha do grupo.

## O que tem

- **Estante**: Lendo, Quero ler e Lido; busca por nome ou ISBN; avaliação; datas; estatísticas e metas.
- **Ler**: EPUB e PDF guardados no próprio aparelho, com acervo gratuito do Projeto Gutenberg.
- **Amigos**: o que o grupo está lendo, com comentários.
- **Mural**: ideias, problemas e pedidos para o app.
